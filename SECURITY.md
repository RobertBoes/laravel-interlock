# Security policy

Interlock enforces who may change a model's state, so a way past that enforcement is a security issue: a transition applied without its authorization, a state written without a transition or a bypass, or a bypass that leaves no record.

## Reporting a vulnerability

Report it privately through [GitHub's vulnerability reporting](https://github.com/robertboes/laravel-interlock/security/advisories/new), not in a public issue. Include the Interlock, Laravel and PHP versions, and the smallest machine and code that reproduce it.

You get a reply within a week. Once a fix is released, the advisory is published with credit to you, unless you'd rather stay anonymous.

## Supported versions

Only the latest release gets security fixes.
